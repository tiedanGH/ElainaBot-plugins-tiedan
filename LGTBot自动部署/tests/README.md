# 本地测试

测试代码、这份说明与夹具清单 (`fixtures/MANIFEST.md`) 进仓库; **夹具本身不进** —— `fixtures/`
下是上传者的真实游戏包, 只做本机备份与回归 (插件目录的 `.gitignore` 只忽略这些)。夹具不在
时, 用到它的用例 SKIP, 其余照跑。

`tests/` 不会同步到测试环境 (`sync_to_test.sh` 对各插件一律跳过): 测试 `.py` 落进插件目录,
框架就会热重载那个插件。

## 跑

```
python tests/run_all.py          # 全部
python tests/run_all.py echo     # 只跑名字含 echo 的套件
```

测试加载的是**同步后的测试环境**那一份 (`ElainaBot_v2/plugins/LGTBot自动部署/`),
不是这个 git 工作区 —— 改完代码要先同步再跑。`run_all.py` 开头会比对两边, 有漂移就提示。

落盘全部进临时沙箱, 跑完自动删; 不会在工作区或测试环境里生成 `data/`
(`run_all.py` 结尾会检查工作区, 出现就报失败)。

## 加新用例

- 遇到新的误判 / 真回显, 把原包放进 `fixtures/` (压缩包直接放, `_env.fixture()` 会解到沙箱),
  在 `MANIFEST.md` 记下记录号、期望结论和**人工核过的理由**, 再在对应套件里加一行。
- 合成用例把期望命中的行标上 `// HIT`, 别手数行号。
- 新套件照 `test_echo.py` 的开头写: `import _env` → `_env.boot(...)` → `ck = _env.Checker()` → 末尾 `ck.done()`。
